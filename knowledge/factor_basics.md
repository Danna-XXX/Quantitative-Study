# 量化因子基础理论

## 什么是因子？

在实证资产定价中，**因子（Factor）** 是指能够系统性地解释或预测资产横截面收益差异的变量。核心逻辑是：不同股票之间的预期收益差异，来自于它们在某个因子上的暴露程度不同。

**因子的两大类型**：
- **风险因子**：承担某种系统性风险的补偿（如市场风险溢价、规模风险溢价）
- **特征因子（Anomaly）**：市场非有效性导致的定价偏差（如动量效应、情绪效应）

---

## 因子的经济逻辑

一个好的量化因子，需要有清晰的**经济逻辑**，而不仅仅是统计显著：

| 因子类型 | 典型例子 | 经济解释 |
|---------|---------|---------|
| 规模因子（SMB） | 小盘股 - 大盘股 | 小公司信息不透明、流动性差，要求额外风险补偿 |
| 价值因子（HML） | 高B/M - 低B/M | 价值股被市场低估，均值回归带来超额收益 |
| 动量因子（MOM） | 强势股 - 弱势股 | 信息扩散缓慢，投资者反应不足 |
| 盈利因子（RMW） | 高盈利 - 低盈利 | 高盈利公司有更稳定的现金流，系统性风险更低 |
| 情绪因子 | 高情绪 - 低情绪 | 投资者情绪偏差导致暂时性定价错误 |

## 因子构造的基本步骤

### 第一步：确定原始信号
原始信号是你拥有的数据，例如：
- 文本分析的情绪打分（如：-1=消极，0=中性，+1=积极）
- 公司财务指标（ROE、利润增长率等）
- 市场交易数据（换手率、波动率等）

### 第二步：信号聚合
将原始信号聚合为**截面变量**（即每个时间点、每个公司一个数值）：
```
F1（水平值）= 当期耐心指数均值
F2（变化量）= F1(t) - F1(t-1)  [一阶差分]
F3（相对变化）= F1(t) - mean(F1(t-1), F1(t-2), F1(t-3))  [相对过去3期均值]
```

### 第三步：数据清洗
- **Winsorize（截尾）**：将极端值裁剪到99.5%分位数，防止极端值干扰
- **标准化**：$(x - \bar{x}) / \sigma_x$，使系数可跨期比较
- **过滤无效观测**：剔除ST股、金融股、科创板等

### 第四步：验证因子效果
- **单变量排序**：最直观的检验方法
- **FM截面回归**：控制其他因素后的净效应
- **因子模型Alpha**：扣除已知风险后的超额收益

## 常见陷阱

1. **未来数据泄露（Look-ahead bias）**：
   - 错误示例：用12月31日的财务数据，预测同年1月的收益
   - 正确做法：财务数据至少滞后一个季度才能使用

2. **数据挖掘（Data mining）**：
   - 多次尝试不同参数直到显著 → 显著性是偶然的
   - 解决：事先定好因子构造逻辑，不要因回归不显著就换因子

3. **微观结构噪声**：
   - 日频数据有买卖价差噪声 → 一般用月频数据

4. **幸存者偏差**：
   - 只使用当前还在上市的公司 → 样本期间已退市公司也要纳入

## A股市场特殊性

- **散户主导**：散户占比高（约60-70%交易量），情绪效应更强
- **ST制度**：濒临退市的ST/*ST股价格异常，通常从样本中剔除
- **涨跌停制度**：日收益不超过±10%，影响价格发现效率
- **信息摩擦**：中小盘股信息透明度低，因子效应往往在小盘股中更强
