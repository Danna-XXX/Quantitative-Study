# 组合排序（Portfolio Sorting）方法

## 什么是组合排序？

组合排序是实证资产定价中**最直观**的因子有效性检验方法。核心思想：

> 如果因子有效，按因子值排序后，高因子组的收益应该系统性地高于（或低于）低因子组。

---

## 单变量排序（Univariate Sort）

### 步骤
1. **形成期（Formation Period）**：在时间 $t$，对所有股票按因子值从小到大排序
2. **分组**：等分为 N 组（通常 N=5 或 N=10），P1=最低因子值组，PN=最高因子值组
3. **持有期（Holding Period）**：在 $t+1$ 期，持有各组股票组合（等权或市值加权）
4. **重复**：每期重复1-3步，得到时序收益率
5. **检验**：对 High-Low（PN - P1）组合做 **Newey-West t 检验**

### 关键设计选择

**持有期滞后（Skip）**：
- skip=1：形成期Q → 持有Q+1（最快，但可能有微观结构偏差）
- skip=3：形成期Q → 持有Q+3（给市场充足时间消化信息）

**权重**：
- 等权（Equal-weight）：对所有股票平均加权，中小盘股影响大
- 市值加权（Value-weight）：按市值加权，更接近可实际投资的组合

**分组数**：
- 5分位（Quintile）：样本量较少时使用
- 10分位（Decile）：样本量充足时使用，H-L 差异更清晰

### 结果解读

**正确解读 H-L 收益**：
- H-L = 0.5%, t = 2.5, ***：表示持有高因子组并卖空低因子组，月均超额收益 0.5%（年化约6%），在1%显著性水平下显著
- **显著性标注**：`*` p<0.10, `**` p<0.05, `***` p<0.01

**Newey-West t 统计量**：
- 标准 OLS t 检验假设误差独立，但时序收益有自相关
- Newey-West HAC（Heteroskedasticity and Autocorrelation Consistent）校正了自相关，更保守（t 值通常更小）

## 双变量排序（Bivariate Sort）

用于：
1. 控制另一个变量后，检验目标因子是否仍然有效（**排除替代解释**）
2. 检验两个因子的交互效应

### 独立双排序（Independent Double Sort）
- 两个因子**分别独立**按分位数排序，取交叉格子
- 结果：$N_1 \times N_2$ 个格子，每格为一个组合
- 优点：每个格子样本量相对均匀
- 适用：检验因子1 和 因子2 是否相互独立地有效

### 条件双排序（Conditional Double Sort / Sequential Sort）
- **先**按因子1分组（通常按中位数分成2组），**再**在每组内按因子2排序
- 结果：在每个因子1分组内，都能看到因子2的 H-L
- 优点：能直接比较"控制因子1后，因子2在不同因子1组的效果"
- 适用：机制检验（如"在信息摩擦高的股票中，情绪效应更强"）

### 示例（条件双排序：市值×情绪因子）
```
           情绪P1   情绪P2   情绪P3   情绪P4   情绪P5   H-L    t
小市值     0.20%    0.35%    0.48%    0.52%    0.68%   0.48%** 2.4
大市值     0.18%    0.22%    0.28%    0.30%    0.35%   0.17%*  1.7

→ 解读：情绪效应在小市值股票中更强（信息摩擦机制支持）
```

## Newey-West 检验的实践注意事项

**滞后阶数（Lag）选择**：
- 月度数据：通常 lag = 4（对应4个月自相关）
- 季度数据：通常 lag = 4（对应4个季度）
- Newey-West(1987) 建议：$\lfloor 4 \times (T/100)^{2/9} \rfloor$

**样本量要求**：
- 至少30-40个时序观测（月），才能让 Newey-West 有统计效力
- 样本量太少时，t 值不可靠

## 组合收益的计算公式

**等权收益**：$r_{p,t} = \frac{1}{N_t} \sum_{i=1}^{N_t} r_{i,t}$

**市值加权收益**：$r_{p,t} = \sum_{i=1}^{N_t} w_{i,t} r_{i,t}$，其中 $w_{i,t} = \frac{MV_{i,t-1}}{\sum_j MV_{j,t-1}}$

**超额收益**：$er_{i,t} = r_{i,t} - r_{f,t}$（月度无风险利率通常用1年期国债收益率/12）
