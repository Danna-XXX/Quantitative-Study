# Fama-MacBeth 截面回归

## 概述

Fama-MacBeth（1973）回归是检验**截面定价关系**最常用的方法。相比组合排序，它的优势是可以**同时控制多个变量**，验证因子效果是否独立于已知因子（规模、价值、动量等）。

---

## 两步骤法

### 第一步：每期截面 OLS 回归

在每个时间截面 $t$，对所有股票做 OLS：

$$r_{i,t+1} = \alpha_t + \beta_t \cdot F_{i,t} + \gamma_{1t} \cdot \ln(MV_{i,t}) + \gamma_{2t} \cdot BM_{i,t} + \gamma_{3t} \cdot MOM_{i,t} + \varepsilon_{i,t+1}$$

其中：
- $r_{i,t+1}$：股票 $i$ 在 $t+1$ 期的超额收益率
- $F_{i,t}$：研究的核心因子（需要事先**标准化**，使系数可比）
- $\ln(MV)$：公司规模（市值对数）
- $BM$：账面市值比（1/PB 的估计）
- $MOM$：动量（过去12-2个月的累计对数收益）

**重要**：每期截面独立标准化，使每期系数的均值、方差可比。

### 第二步：对系数时序做 t 检验

收集 T 期的系数：$\{\hat{\beta}_1, \hat{\beta}_2, ..., \hat{\beta}_T\}$

用 Newey-West HAC t 检验：

$$\bar{\beta} = \frac{1}{T}\sum_t \hat{\beta}_t, \quad t_{NW} = \frac{\bar{\beta}}{SE_{NW}(\hat{\beta})}$$

---

## 模型递进（逐步加入控制变量）

通常按以下顺序汇报结果：

| 模型 | 变量 | 目的 |
|------|------|------|
| M1 | 仅因子 F | 因子的原始效果 |
| M2 | F + ln(MV) | 控制规模效应 |
| M3 | F + ln(MV) + BM | 再控制价值效应 |
| M4 | F + ln(MV) + BM + MOM | 再控制动量效应（完整规格） |

**论文写作要求**：通常展示所有模型，重点关注 M4（完整规格）中因子是否仍然显著。

---

## 数据处理规范

### Winsorize（截尾处理）
```python
# 每期截面独立 winsorize，防止极端值影响回归
lo = X.quantile(0.005)
hi = X.quantile(0.995)
X_win = X.clip(lo, hi)
```

### 标准化
```python
# 使系数可比（不同期、不同因子）
X_std = (X_win - X_win.mean()) / X_win.std()
```

### 滞后处理（避免 Look-ahead bias）
- 因子 F：使用**形成期**数据（t 期末），预测 **t+1 期**收益
- 控制变量：
  - 市值（MV）：使用 t 期末的市值
  - BM：使用最新可获得的财务报告数据（通常滞后1-2个季度）
  - 动量：通常跳过最近1个月（$t-12$ 到 $t-2$ 的累计收益）

## 结果解读示例

```
变量         均值系数    t统计量    显著性
情绪因子      0.00135    3.173      ***
ln(MV)       -0.00466    -1.892     *
BM            0.00234    1.456      
MOM           0.00187    2.341      **
```

**解读**：
- 情绪因子系数 = 0.00135：情绪因子提高1个标准差，月均超额收益提高 0.135% ≈ 13.5个基点
- 控制规模、价值、动量后，因子效果仍在1%水平显著（t=3.17>2.58）
- 规模系数负值：符合A股规模效应（小盘股收益更高）

## 与组合排序的比较

| 维度 | 组合排序 | FM回归 |
|------|---------|--------|
| 控制变量 | 只能一次控制1-2个 | 可同时控制多个 |
| 非线性关系 | 能发现非线性（各组收益） | 假设线性关系 |
| 统计效率 | 较低（使用组合均值） | 较高（使用所有个股） |
| 结果直观性 | 非常直观（高低组收益差） | 需要理解系数含义 |
| 常见组合 | 两者**互为补充**，论文中通常都汇报 | |
